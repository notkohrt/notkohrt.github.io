# notkohrt.pro

STS2 Bubble is a Slay the Spire 2 knowledge graph built from pinned data and shared mechanical parsers. The root `index.html` is self-contained and generated from `src/index.html`, `styles.css`, `app.js`, `lib/`, and `data/`.

After editing source or curated relationships, run `npm run build:site` and `npm run check`. See [DEVELOPMENT.md](DEVELOPMENT.md) for semantic policy, browser checks, snapshot updates, and Obsidian generation.

Slay the Spire 2 and its game content are by [Mega Crit](https://www.megacrit.com/). STS2 Bubble is an unofficial fan project. See [CREDITS.md](CREDITS.md) for attribution and the status of artwork permission for notes.
